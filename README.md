# Customer Segmentation using K-Means Clustering
  Create a K-means clustering algorithm to group customers of a retail store based on their purchase history.

This project demonstrates how to perform customer segmentation using the K-Means clustering algorithm. The objective is to group customers based on common features and behaviors, which can help businesses in targeted marketing, personalization, and better understanding of customer needs.

## 📁 Project Structure

- `customer_kmeans_clustering_.ipynb`: Jupyter Notebook containing the full implementation of K-Means clustering on customer data.
- `README.md`: Project overview and instructions.
- `requirements.txt`: List of Python dependencies (if applicable).

##  Install dependencies:

`pip install -r requirements.txt`

## 🚀 Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Optimal number of clusters using the Elbow Method
- K-Means clustering
- Cluster visualization
